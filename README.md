# Birleştir Adası

Telefonda tarayıcıdan oynanan bir birleştir ve büyüt (merge) oyunu. Tahtadaki aynı eşyaları birleştirip daha değerlilerini yap, müşteri siparişlerini tamamla, kazandığın parayla kafeni adım adım yenile. Enerji sistemi, günlük ödül ve demo mağaza içerir (ödemeler şimdilik demo).

Oynamak için `index.html` dosyasını tarayıcıda aç veya GitHub Pages linkini kullan.
